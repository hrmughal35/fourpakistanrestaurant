# FOUR Restaurant — Premium Website Concept

Award-worthy, ultra-premium restaurant website for **FOUR Restaurant**, Lahore, Pakistan.

## Stack

- Next.js 15
- TypeScript
- Tailwind CSS v4
- Framer Motion
- GSAP + ScrollTrigger
- Lenis smooth scroll
- Shadcn-style UI (Radix tabs, CVA buttons)

## Features

- Cinematic fullscreen video hero
- Luxury loading screen
- Custom cursor & magnetic buttons
- Horizontal scroll storytelling timeline
- Apple-style burger product showcase with 3D tilt
- Animated interactive menu with category tabs
- Masonry gallery with hover reveals
- Animated review counters & testimonial slider
- Interactive branch map
- FoodPanda & WhatsApp ordering CTAs
- Instagram-style feed
- Floating sauce particles, burger cursor follower
- Scroll-triggered ingredient explosion
- Ambient sound toggle

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

Edit `src/data/site.ts` for menu items, branches, social links, and brand copy.

Replace the hero video URL in `HERO_VIDEO` with your own slow-motion food footage for production.

## Production

```bash
npm run build
npm start
```
